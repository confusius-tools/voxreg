# Bounded linear-model qualification

> Historical qualification record. The exploratory runner was removed; numerical
> production tests remain. See [archive scope](../README.md) and the [current benchmark](../../BENCHMARK.md).

For the current package-first API/test audit and fresh ConfUSIus workflows, see
[READINESS.md](READINESS.md). The measurements below retain their original
protocol and source hashes; the readiness check does not rewrite them.

This extends the rigid engine to translation and affine fitting. It is a
**quality/precision check, not a performance benchmark or general capture-range
claim**. Frozen rigid benchmark measurements are not reclassified as affine data.

Reproduce from the repository root:

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  uv run python research/linear/qualify.py
```

`qualify.py` generates six deterministic analytic controls: translation, rigid and
affine in 2D and 3D. A mixture of 16 Gaussians is sampled independently on unequal,
orthogonal fixed/moving grids. The known physical pull includes small translations
and, by model, rotation or scale/shear. Native grids remain orthogonal: affine
anatomy is generated by evaluating the continuous field through the inverse truth,
not by placing shear into an ITK direction matrix. These are synthetic volumes,
not independent biological acquisitions.

Every backend uses the same original float64 values, physical inputs, geometric
center initialization and **160 fixed updates**. The convergence window is 161.
ITK 5.4.7 uses native TranslationTransform / Euler2DTransform / Euler3DTransform /
AffineTransform, double images, negative squared correlation, single-level GD at
0.1, native physical-shift scales, best-parameter return, and one CPU thread.
Voxreg uses the production mixed-precision engine, Adam at 0.1, fixed-grid RMS
physical scales, and one CPU thread or CUDA. The same budget/nominal learning rate
is not a matched optimizer trajectory. No timing, memory or speedup is inferred.

All final matrices are scored independently with SciPy float64 linear pulls on
**joint backend support**, with squared NCC and physical truth error. Joint support
is 100% on these controls. RMS truth is over all fixed voxel centers, divided by
minimum active fixed spacing. The CPU/CUDA precision screen is the maximum
pointwise transform disagreement over the same domain, not a parameter tolerance.

| Control | voxreg CPU truth RMS (px) | CUDA truth RMS (px) | ITK truth RMS (px) | CPU/CUDA max (px) |
| --- | ---: | ---: | ---: | ---: |
| 2D translation | 0.001482 | 0.001511 | 0.002642 | 0.00008545 |
| 2D rigid | 0.007082 | 0.007082 | 0.025413 | 0.0000000318 |
| 2D affine | 0.042207 | 0.042207 | 0.065112 | 0.0000001066 |
| 3D translation | 0.001150 | 0.001194 | 0.004394 | 0.00007018 |
| 3D rigid | 0.004229 | 0.004160 | 0.010340 | 0.00038783 |
| 3D affine | 0.035919 | 0.035919 | 0.038575 | 0.0000000427 |

**All 18 backend/control truth checks pass the unchanged 0.25-pixel RMS gate;
all six CPU/CUDA comparisons pass the unchanged 0.001-pixel maximum gate.**
The independent NCC² scores range from 0.9990019 to 0.9996749. `results.json`
retains full matrices, scores, update counts, software versions, deterministic
input hashes and source hashes. The script writes results before asserting gates,
so failures remain observable rather than being dropped from the report.

`tests/test_linear.py` additionally checks native ITK point oracles, full affine
seed refinement (not a frozen prefix), float64 SciPy resampling and finite-difference
gradients, pivot-dependent scales, oblique/sheared/cropped/strided geometry,
same-grid slice arithmetic, labeled/batched seeds, implicit identity references,
CPU/CUDA batch independence, reflection seeds, invalid matrices, orientation and
singularity guards, per-frame failure isolation, float64 low-contrast output and
default/explicit rigid equivalence.

## Qualification limits

- Default early stopping remains calibrated on rigid slices only. The previously
  observed default 3D centering precision failure remains documented in
  [VALIDATION.md](../../VALIDATION.md); this fixed-budget report does not resolve it.
- Affine's finite normalized determinant/orientation guard is not anatomical
  regularization. It does not guarantee plausible scaling, robust partial overlap,
  global optima, reflection discovery, or large-displacement/large-strain capture.
- No natural independently acquired 3D pair, affine real-series benchmark,
  multiresolution, masks, deformable model or slice-to-volume alignment is qualified.
- `register_rigid` was removed from the pre-release API in favor of the single
  `register` function, whose default remains rigid. Live research imports were
  updated; ignored historical source snapshots and measured rigid results remain
  unchanged.
