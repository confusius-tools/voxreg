# 3D SyN convergence investigation

## Scope and outcome

CPU diagnostics reproduce the frozen 100-update failure and show continued
improvement with more updates. Larger learning rates do not provide a robust
fix across held-out phantoms/geometries. No production code, default, accuracy
gate or official benchmark workload was changed. Directional preconditioning
was explored separately and discarded at the operator's request.

These are correctness diagnostics with two Torch threads, not throughput
measurements or CUDA qualification. A separate local GPU job was left untouched.
Frozen data, source copies, scripts, fields and JSON results remain in
`artifacts/syn-accuracy-20261112-01/`. The source pair is from
`artifacts/syn-profile-baseline-20261111-042439/inputs/3d-syn/`; its input hash is
verified by the original benchmark loader.

## Budget diagnosis

Same original images, learning rate 0.1, no early stopping:

| Updates | Full-grid truth RMS, minimum-spacing voxels |
| ---: | ---: |
| Identity | 0.508400 |
| 25 | 0.400014 |
| 100 | 0.306434 |
| 300 | 0.184296 |

The 100-update result exactly reproduces the earlier CPU benchmark. The best
midpoint loss occurs at update 100, not an incorrectly selected earlier state.
Its approximate endpoint from the difference of halfway fields has RMS 0.306394,
close to the finalized map's RMS; this comparison is diagnostic, not a proof
that composition/inversion errors vanish. All 100 updates execute, support is
complete and final sampled Jacobians are positive. Error decreases with a longer
budget: the fixed 100-update case is under-converged in physical truth accuracy.
This does not prove mathematical convergence at 300 or establish its cause.

instruments every midpoint evaluation. An initial held-out-probe hashing harness
failure is preserved; the corrected version supplies all required hash arrays.

## How close is the update to ITK?

The pinned [ITK SyN reference](https://github.com/InsightSoftwareConsortium/ITK/blob/090ded25eff27f6d76888836538f7a16900cb327/Modules/Registration/RegistrationMethodsv4/include/itkSyNImageRegistrationMethod.hxx)
provides an algorithmic reference, not evidence of bitwise identity with the
installed ANTs binary.

- **Step normalization:** on axis-aligned grids, both smooth the physical update,
  measure its maximum voxel-space norm and multiply the whole field by learning
  rate / maximum norm. voxreg uses the full inverse lattice for oblique/sheared
  geometry. This is already coordinate-aware scalar normalization, not a missing
  directional preconditioner.
- **Metric derivatives:** voxreg differentiates one joint masked halfway local-NCC
  objective through both pulls. ITK computes metric-derived updates with the
  image roles swapped. Derivative evaluation and numerical/boundary conventions
  are not established as identical.
- **Smoothing:** voxreg uses sampled Gaussian kernels with replicate padding and
  fixed boundaries. ITK uses discrete Gaussian operators, also fixes boundaries,
  and blends smoothed/original values for small positive variance. Our nominal
  update sigma 1.5 / total sigma 0.5 correspond to ANTs variance parameters
  2.25 / 0.25, but that does not make the filters equivalent.
- **Inverse maintenance:** ITK repeatedly estimates inverse fields and re-inverts
  them within every outer iteration (up to 20 iterations per inversion with
  residual-based stopping). voxreg fits halfway pulls and finalizes both inverses
  with 80 iterations, retaining double finalization and additional diagnostics.
  Field directions/composition must be traced before transplanting any step.
- **State selection:** voxreg retains the best usable halfway objective per frame;
  trajectories/stopping rules are not identical to ITK's.

Keep the current ITK-like scalar normalization. Exact imitation would require a
separate, measured study of derivative, smoothing and inverse-maintenance semantics,
not copying one function or claiming identical optimizer work. The next question
is which of those differences materially limits useful convergence. Larger global
learning rates alone have not resolved it.
